1.2 User Roles & Access Levels

The portal uses a role-based access control system with four distinct roles, each with specific permissions:

Role Description Access Level
Admin Full system access including settings, role management, and all administrative functions Complete
Office Manager Can manage members, approve bookings, record payments, import data, and access most admin features High
Office Staff Can view members, process day-to-day transactions, record payments, and handle basic admin tasks Standard
Member Portal access for viewing own profile, registering for events, and making payments Self-Service Only

Permissions Matrix

System settings No Limited Yes

1.3 Logging Into the Portal

The portal supports two secure login methods:

Google Sign-In (Recommended)

  1. Navigate to the portal login page
  2. Click the "Sign in with Google" button
  3. Select your Google account or enter credentials
  4. You will be automatically redirected to the dashboard

Magic Link (Email)

  1. Navigate to the portal login page
  2. Enter your registered email address
  3. Click "Email Me a Link to Login"
  4. Check your email inbox for the login link
  5. Click the link within 1 hour to sign in
Note
Magic links are single-use and expire after 1 hour. If the link doesn't work, request a new one.

3.5 Bulk Import (CSV)

Navigate to /admin/members/import to import multiple members from a CSV file.

Access Required
Bulk import is available to Office Managers and Admins only.

CSV Format

The CSV file must include the following columns (42 total supported):

Required Columns

  • Member_First_Name
  • Member_Last_Name
  • Primary_Member_Email_Address

Optional Columns

  • Member_Number - Leave blank to auto-generate
  • Member_Class - Personal or Business
  • Member_Type - Community, Annual, or Lifetime
  • Business_Name, Business_EIN
  • Primary_Phone_Number_1, Primary_Phone_Number_2
  • Secondary_First_Name, Secondary_Last_Name, etc.
  • Child_1_First_Name through Child_4_First_Name (template supports 4 children columns; more can be added via admin portal after import)
  • Address_1, City, State, Zip, Country

Import Workflow

  1. Prepare your CSV file with member data
  2. Click "Upload CSV File" and select your file
  3. Review the preview table - green checkmarks indicate valid records, red X marks show errors
  4. Fix any errors in your CSV and re-upload if needed
  5. Click "Import X Valid Members" to proceed
  6. View the import results showing success and failure counts
Important
  • Member numbers must be unique
  • Invalid rows are skipped but don't stop the import
  • Family members (spouse, children) are created automatically
  • Review the Import History page to track all imports

5.3 Zelle Payment Processing

Access at /admin/zelle. Process and confirm Zelle payment requests.

Zelle Payment Status Flow

Member Requests
→
Pending
→
Member Confirms
→
Auto or Staff Confirms
→
Completed

Status Types

StatusDescription
pendingRequest created, awaiting member action
member_confirmedMember marked as sent, awaiting staff confirmation
auto_confirmedAuto-confirmed (amount ≤ threshold, default $50)
staff_confirmedStaff verified and confirmed receipt
expiredRequest expired (default: 48 hours)
cancelledCancelled by member or staff

Reference Code Format

Zelle reference codes use the format: HSNEF-Z-XXXX (4 alphanumeric characters, excluding confusing characters like 0/O and 1/I)

Processing Workflow

  1. Member initiates: Clicks "Pay with Zelle" and receives reference code (e.g., HSNEF-Z-A7X3)
  2. Member transfers: Sends payment via their bank's Zelle to configured email/phone
  3. Member confirms: Clicks confirmation on portal, optionally enters bank confirmation number
  4. Auto or Staff confirms: If amount ≤ $50 (configurable), auto-confirms immediately. Otherwise, staff must verify and confirm.
  5. Payment recorded: System creates payment record and marks complete
Tip
Filter by "Ready to Confirm" status to see payments that need staff action. The dashboard auto-refreshes every 30 seconds.
Walk-in Support
Zelle requests can be created without a linked member account, supporting walk-in customers at the temple.

5.4 Generating Receipts

8. Settings & Configuration

8.1 Staff Role Management

Access at /admin/settings/staff-roles. Assign and manage administrative roles.

Admin Only
Staff role management is restricted to Admins only.

Assigning Roles

  1. Search for the member by name or email
  2. Select the member from search results
  3. Choose the role to assign (Admin, Office Manager, or Office Staff)
  4. Click "Assign Role"
Requirement
Members must have registered on the portal (logged in at least once) before they can be assigned a role.

Removing Roles

  • Find the staff member in the Current Staff table
  • Click the × button next to the role to remove
  • Confirm the removal

Admin Protection

The system prevents accidental lockout:

  • At least one non-test Admin must exist at all times
  • The last remaining Admin cannot remove their own role
  • Assign Admin to another user before removing your own

9.3 Helping Members (FAQ)

Q: How do I change my email address?

A: Members cannot self-service email changes. The email is linked to authentication for security. Staff must update the email in the member's profile.

Q: Can I add more than 4 family members?

A: The member self-service portal allows up to 4 family members. If more are needed, contact the office - staff can add additional family members through the admin portal with no limit.

Q: When does my membership expire?

A: Annual memberships expire December 31st each year. Lifetime members never expire. Members can check their dashboard for the exact date.

Q: How do I download my receipts?

A: Go to Payments page, click "Download Receipt" on any payment, or download all receipts for the year.

Q: Can I cancel my event registration?

A: Yes, go to the event details page and click "Cancel Registration" (as long as the event hasn't started).

Q: Are donations tax-deductible?

A: Yes, all donations are tax-deductible. Members can download receipts from the Payments page for tax records.

Q: How does Zelle payment work?

A: Create Zelle request → System shows where to send payment → Send from your bank with reference code → Confirm payment sent on portal.

Q: The QR code isn't scanning. What do I do?

A: Try refreshing the membership pass page. If still not working, use Manual Lookup mode in the scanner by entering the member ID or name.

10. Reference

10.1 Common Workflows

Workflow 1: Register a New Member

  1. Navigate to Members → Add Member
  2. Select member type (Personal or Business)
  3. Fill in required fields: Name, Email
  4. Add contact information and address
  5. Set membership level (Annual, Lifetime, Community)
  6. Check "Send registration invitation" if desired
  7. Click Create Member

Workflow 2: Create and Publish an Event

  1. Navigate to Events → Create Event
  2. Enter event name, date, time, and location
  3. Select category and upload image
  4. Write short and full descriptions
  5. Enable RSVP and set capacity if needed
  6. Enable payment and set pricing if paid event
  7. Set status to "Published"
  8. Click Create Event

Workflow 3: Record a Cash/Check Payment

  1. Navigate to Payments → Record Payment
  2. Search and select the member
  3. Enter the payment amount
  4. Select payment date and method (Cash or Check)
  5. Enter check number if applicable
  6. Select payment purpose
  7. Add notes if needed
  8. Click Save Payment

Workflow 4: Verify Member at Temple

  1. Open QR Code Scanner
  2. Point camera at member's QR code (or use Manual Lookup)
  3. Verify member information displays correctly
  4. Click "Record Check-In" to log the visit
  5. Click "Scan Next Member" to continue

Workflow 5: Process Zelle Payments

  1. Navigate to Zelle Payments
  2. Filter by "Ready to Confirm" status
  3. Verify payment was received in bank account
  4. Click "Confirm" for each verified payment
  5. Payment is automatically recorded

Workflow 6: Assign Admin Role to Staff

  1. Ensure staff member has registered on portal (logged in once)
  2. Navigate to Settings → Staff Roles
  3. Search for the member by name or email
  4. Select from search results
  5. Choose role (Admin, Office Manager, or Office Staff)
  6. Click Assign Role
